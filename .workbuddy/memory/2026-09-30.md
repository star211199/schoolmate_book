## 功能扩展调研（已给用户建议清单，待决策）

用户问「项目还能怎么优化、加什么功能，搜一下别人的项目」。调研 7 个同类项目后给出优先级清单。

### 参考的项目与借鉴点
- **High-School-Memoir**（togithub.com/CanFlyhang/High-School-Memoir）：话题标签、公告栏、消息通知中心
- **拾光同学录**（纯前端，juejin.cn/pin/7682633827692986420）：留言卡片一键生成分享图
- **GitHub Graduation Yearbook**：每人一句毕业寄语（quote）
- **AlumNet / 校友管理平台 / 校友管理系统（Gitee 有朋自远方来）**：ECharts 数据看板、Excel 导入导出、毕业去向统计、操作日志（Spring AOP）、AI+定时任务更新数据
- **班小二小程序**：通知已读/未读、倒数日（本项目已有）、课程表
- **同学信息管理工具**：拼音首字母搜索、vCard 导出、生源地统计

### 建议优先级（P0→P2）
- **P0**：时光胶囊补完（表/实体/Mapper 已建，只差 Service+接口+页面）、找回密码（现在完全没有）、
  通知中心（好友申请/点赞/评论无统一入口）、通讯录导出（EasyExcel）、Element Plus 按需引入
- **P1**：班级公告（置顶）、@ 提醒、毕业去向 + 数据看板（ECharts）、生日提醒（定时任务群发祝福）、
  大事记时间轴、分享卡片（canvas 生成图片）
- **P2**：班级树洞（匿名）、青春地图、全文搜索、操作日志（AOP）、投票
- **技术项**：上传 magic number 校验（现在只查后缀）、接口限流、Refresh Token（JWT 现在 24h 过期要重登）、
  单测 + GitHub Actions CI、Docker 化、Redis 破单机限制

### 确认的缺口事实（grep 过）
- 找回密码：`AuthController` 只有 register/login/me
- 通知中心：无 NotificationController，社交事件散落各处
